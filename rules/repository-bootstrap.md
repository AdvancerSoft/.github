# Repository Bootstrap Checklist

Apply this checklist when creating a new AdvancerSoft repository.

- Create repository as private.
- Set default branch to `main`.
- Add README and repository-specific `.gitignore`.
- Add `.github/pull_request_template.md`.
- Add CI-only workflow.
- Enable branch protection for `main`.
- Disable direct pushes to `main`.
- Confirm no production secrets are present.
- Confirm repository purpose and owner.
